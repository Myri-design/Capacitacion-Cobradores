# Capacitación para Cobradores de Estudios Jurídicos

Aplicación web estática mobile-first para registrar y organizar información de cobranzas.

## GitHub Pages
1. Descomprimí el ZIP.
2. Subí el contenido de esta carpeta a un repositorio.
3. `index.html` debe quedar en la raíz.
4. GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
5. Guardá y abrí el enlace generado.
6. Desde Safari/Chrome podés usar “Agregar a pantalla de inicio”.

No requiere Node.js, npm, React, Vite, backend ni comandos de terminal.

## Datos
Los registros se guardan localmente mediante `localStorage`. La primera apertura incluye datos de demostración, eliminables desde Configuración.

## Alcance
La aplicación organiza registros de cobranzas y no brinda diagnósticos ni reemplaza la consulta con profesionales del tratamiento de clientes morosos.
